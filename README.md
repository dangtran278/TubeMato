# TubeMato

A lightweight Electron desktop app for Pomodoro time tracking, YouTube playback control, task management, and goal accountability.

---

## Features

- **Pomodoro Timer** — Work / Short Break / Long Break with configurable durations
- **YouTube Integration** — Paste any video or playlist URL; audio fades in/out automatically, with a bell tone at each session transition
- **Procrastination Tracking** — 10-second grace period after break; idle time logged automatically
- **Task Management** — Kanban board (Pending → In Progress → Done)
- **Goal System** — One-time and repeating goals (every N days/weeks), spread or end-of-period reminders
- **Daily Summary** — Shown during a break at your configured time, or on next startup if you were away
- **Analytics** — Focus time bar chart, procrastination trend, 4+ pomodoro streaks
- **Mini Floating Widget** — Always-on-top semi-transparent countdown, non-focus-stealing
- **System Tray** — Full control without opening the main window
- **Auto-launch** — Starts with Windows (toggle in Settings)
- **Log Rotation** — Monthly (or configurable) JSON log files, all browsable in Analytics

## Getting Started

```bash
# 1. Install dependencies
npm install

# 2. Generate placeholder tray icons (required before first run)
npm run generate-icons

# 3. Start in development mode
npm run electron:dev
```

## Project Structure

```
TubeMato/
├── electron/          # Main process (timer engine, store, IPC, scheduler)
├── src/               # Renderer (React + Vite)
│   ├── components/    # Timer, Tasks, Goals, Analytics, Settings views
│   ├── hooks/         # useTimer, useYouTube, useAudio
│   ├── store/         # Zustand state stores
│   └── types/         # window.tubemato type declarations
├── widget/            # Floating mini widget (standalone HTML)
├── assets/icons/      # Tray + app icons (generated by generate-icons script)
└── scripts/           # Dev utilities
```

---

## Data Storage

All data is stored locally in your user data directory:

- **Windows**: `%APPDATA%\tubemato\`
  - `tubemato.json` — settings, tasks, goals, pending summary
  - `logs\log-YYYY-MM.json` — session logs per rotation period

No data is sent anywhere. Everything is offline.

---

## YouTube Notes

- Paste any YouTube video URL or playlist URL (e.g. `youtube.com/playlist?list=PLxxxxx`)
- Shuffle is enabled by default for playlists (toggle in Settings)
- If a video is not embeddable, the timer continues but YouTube won't be controlled
- Private/age-restricted playlists will not load

## Replacing Icons

After first run, replace the placeholder icons in `assets/icons/` with your final artwork:

| File | Usage | Recommended size |
|---|---|---|
| `icon.png` | App window + taskbar | 512×512 |
| `tray-work.png` | System tray — working | 16×16 |
| `tray-break.png` | System tray — on break | 16×16 |
| `tray-pause.png` | System tray — paused | 16×16 |
| `tray-idle.png` | System tray — idle | 16×16 |
